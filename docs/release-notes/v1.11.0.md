# 家庭影院 v1.11.0

## Windows 一键部署

下载同一 Release 的 Windows EXE，选择程序与媒体目录后安装。支持 Windows 10/11 x64，界面采用与家庭影院一致的 Material 3 绿色主题，支持浅色、深色及跟随系统。

- 自动准备独立 Go 环境，从固定源码版本编译主服务与盘搜，不需要自行安装开发工具或 Docker。
- 盘搜默认勾选；声音与字幕处理、局域网访问和登录后启动按需选择。
- 多个镜像后台并发测速，自动选择可用快源，失败切换备用；源码、工具和 APK 必须通过固定 SHA-256 校验。
- 国内工具和 Go 镜像直连，避免显式代理绕远；不修改系统代理、PATH 或全局开发环境。
- 支持安装、更新、启停、日志和取消。升级保留配置与媒体，遇到活动下载、上传或转码任务时不停止现有服务。
- 手机 App 自动下载并托管，盘搜通过主服务同源访问，不直接开放其本机端口。

系统需要 .NET Framework 4.8 和微软 WebView2 Runtime。缺少 WebView2 时自动获取微软引导程序，先验证可信微软数字签名，再准备运行环境。

## Android 1.11

同一 Release 提供 `com.family.cinema` 正式签名 APK，versionCode 为 12。安装器直接下载已编译 APK，用户电脑不需要 Android SDK、Java 或 Gradle。

**旧调试版不能直接覆盖为正式版。** 首次从历史调试版迁移需要卸载旧包，卸载会删除 App 私有缓存、设置及本地记录，请先保留需要的数据；服务器影片不受影响。后续正式版继续使用相同发布签名，可按递增版本正常覆盖升级。

## 使用提醒

- 仅用于可信家庭局域网，不要将管理端口映射到公网。
- 启用 FFmpeg 后，会在处理结果校验成功后替换需要转换的原视频；请先了解该行为并保留重要原片。
- Windows EXE 暂无商业代码签名，请从本仓库 Release 获取并核对 `SHA256SUMS.txt`，不要关闭系统安全保护去运行不明修改版。
- 开机自启指当前用户登录后启动，不是无人登录的 Windows 系统服务。
- 下载源、内容站和网络环境各不相同，镜像测速与切换不能保证第三方站点永久可达。

已验证 Windows 实际源码编译、盘搜真实搜索、主服务接口、APK 托管哈希、重复启动与盘搜补启动、更新保留及失败恢复、真实 AC3 转 AAC 流程，以及 MD3 页面状态和不同窗口尺寸。维护者网络的验证不等于所有用户网络或手机型号均已验收。

安装说明见仓库 `docs/windows-installation.md`，Android 签名和迁移说明见 `docs/android-release.md`。
