# Windows 一键部署

## 安装

支持 Windows 10/11 的 64 位 x86 电脑，需要 .NET Framework 4.8。Windows 11 与近期 Windows 10 已带有相应运行环境。不支持 32 位 Windows；ARM Windows 暂未作为原生目标验证。

界面使用与家庭影院相同的 Material 3 视觉风格，支持浅色、深色和跟随系统。页面、图标和样式内嵌于 EXE，不依赖外部网页。系统缺少微软 WebView2 Runtime 时，安装器从微软获取引导程序，验证其可信微软数字签名后准备运行环境；取消或失败不会覆盖既有家庭影院。

从本仓库 Releases 下载 `family-cinema-windows-setup-版本.exe`，打开后选择程序目录和媒体目录，再选择需要的组件。首次安装需要下载 Go、源码和所选组件，并在本机编译主程序与 PanSou；不需要自行安装 Git、Go、Node.js、Java、Android SDK 或 Docker。

PanSou 网盘搜索默认勾选，可以取消。声音转换和字幕处理是可选功能：它会在验证输出成功后替换需要转换的原片，选择前应了解现有媒体处理行为。安装过程不下载影片。

安卓 APK 由项目发布者提前编译并签名，与安装器放在同一 Release。安装器下载后核对校验值，并生成主服务的 App 版本信息。手机安装 APK 仍需要在系统界面确认。

## 目录与数据

程序目录用于主程序、安装状态、日志和工具；媒体目录用于影片、番剧、下载及下载缓存。请选择专用的媒体文件夹，不要把整个系统盘、用户文档目录或已有软件目录作为媒体根。

下载缓存与媒体目录放在同一块盘上，可以避免下载完成后跨盘复制。不要在下载或转码期间移动媒体目录、拔出硬盘。

安装器仅管理本次安装登记的进程，不按进程名称结束其他软件。更新会保留媒体与运行数据；应使用同一程序目录识别已有安装。不要手动删除应用配置、媒体处理状态或番剧缓存后再期待恢复原记录。

更新前会检查正在运行的下载、上传和媒体处理任务。有任务时保留原服务并提示稍后更新；编译完成、实际切换版本前还会再检查一次。观看中的视频会因服务重启中断，请选无人观看时更新。

## 手机访问

选择局域网访问后，手机和电脑需要处于同一可信局域网。电脑睡眠、关机或退出服务后，手机将无法访问电脑上的内容。

主服务通常使用 TCP 8088；自动发现使用 UDP 45222。安装器的防火墙操作只针对本程序、专用网络和本地子网。家庭网络应使用 Windows 的专用网络配置，不应为排查问题关闭整个防火墙。

在手机上安装同一 Release 的 APK，让 App 自动发现服务，或在设置里填写电脑的局域网服务地址。APK 也可以从电脑主服务的 `/api/app/apk` 下载。

主服务没有公网登录保护，请不要把服务端口映射到公网。Windows 版不部署安卓盒子专用的 ADB、挂载修复或救援脚本。

## 下载与更新

安装器会后台并行下载几个镜像中实际文件的一小段，按实际速度选择可用源，失败后自动切换备用源，并缓存近期测速结果。源码、Go 环境和 APK 都应通过发行时固定的 SHA-256 校验，镜像不能决定要执行哪个版本。

镜像并不保证永久可用；下载失败时保留错误和日志，检查网络后重试。安装阶段能下载成功，也不代表第三方内容站在该网络下都能访问。站点访问限制和账号要求不会因为安装器而消失。

国内 Go 和工具镜像绕过显式代理，避免因为电脑后台代理而绕远；其他源根据当前代理环境访问。这个设置只影响本安装器及其编译进程，不关闭用户的代理软件，也不修改系统代理或 TUN 设置。

Windows 可执行文件目前没有商业代码签名。请从本仓库 Release 下载，核对同页的校验文件，不要关闭系统安全保护来运行来源不明的修改版。

Android 正式包使用固定发行签名；历史调试包无法直接覆盖为正式包，迁移方式见 [Android 发布说明](android-release.md)。

## 发布者构建

安装器源码位于 `windows/`，发行打包脚本位于 `scripts/`。APK 由 Android 发布脚本生成，发行包中的版本、源码提交和校验值必须与实际产物相符。

请先完成源码测试、网页构建、Windows 真正安装验证和 APK 签名验证，再发布同一个 Release。不要把本地配置、签名私钥或编译缓存作为发行附件上传。

发布者先编译 APK、提交并推送源码，再下载该提交的源码 ZIP，以免安装器引用不存在的提交。使用 `scripts/package-windows-release.ps1`，通过 `-Tag`、`-SourceCommit`、`-SourceArchive`、`-Apk`、`-ApkVersionCode`、`-ApkVersionName`、`-OutputDirectory` 传入真实发行信息。脚本读取 `windows/component-versions.json` 中固定的可选组件版本，生成内嵌校验信息的 EXE、APK 元数据与 `SHA256SUMS.txt`。默认仅打包文件，不自动提交或发布。

APK、EXE、`release-settings.json`、`app-version.json`、`SHA256SUMS.txt` 应一并上传至 `-Tag` 对应的同一个 Release。更新外部组件时，重新核实其上游版本、文件摘要与许可，再修改组件清单。
